# Changelog

Lightspeed has not made its first public release yet.

## 0.1.0 - Unreleased

### Added

- Initial `@lightspeed/core` package for browser speed-test runs, result
  records, plans, quality scoring, diagnostics, and test helpers.
- Initial `@lightspeed/config` package for runtime config defaults, validation,
  normalization, loading, and export helpers.
- Production app source for deployments that load `/lightspeed.config.json`.
- Playground source for tuning runtime config and endpoint behavior.
- Open-source project files: MIT license, contribution guide, security policy,
  issue templates, and pull request template.
